# API Module Documentation

The `app.api` package encapsulates all HTTP route definitions for MAAYA.

## Endpoints Roadmap

- `GET /health` — Application health check and status.
- `POST /api/chat` — Conversational interaction with the assistant.
- `GET /api/memory` — Inspect stored long-term memories.
- `POST /api/memory` — Explicitly add or approve a long-term memory.
- `DELETE /api/memory/{id}` — Delete a stored memory.
- `GET /api/projects` — List active projects and ideas.
- `POST /api/projects` — Create or update a project or note.
- `GET /api/reminders` — Retrieve pending reminders and tasks.
