# Projects & Idea Vault Module

The `app.projects` package handles user projects, decisions, ideas, and tasks.

## Capabilities

- **Project Tracking:** Structured tracking of ongoing personal initiatives, goals, and milestones.
- **Decision Log:** Records architectural, technical, or personal decisions alongside their context and rationale.
- **Idea Vault:** Capture early-stage concepts without cluttering main conversational memory or active task lists.
